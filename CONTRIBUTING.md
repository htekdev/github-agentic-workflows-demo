# Contributing

Thanks for your interest in contributing to this project! Here's how to get started.

## Getting Started

1. **Fork** the repository
2. **Clone** your fork locally
3. **Create a branch** for your change:
   ```bash
   git checkout -b my-feature
   ```
4. **Install dependencies:**
   ```bash
   npm install
   ```

## Making Changes

- Follow the existing code style and patterns
- Keep changes focused — one feature or fix per PR
- This is a demo repo, so keep things simple and readable

## Running Tests

Always run tests before submitting a PR:

```bash
npm test
```

## Submitting a Pull Request

1. Push your branch to your fork
2. Open a pull request against `main`
3. Describe what your change does and why
4. Ensure all tests pass

## Reporting Issues

Issues are welcome! Please include:

- A clear description of the problem or feature request
- Steps to reproduce (for bugs)
- Expected vs. actual behavior
- Node.js version (`node -v`)

## Code of Conduct

Be kind and constructive. We're all here to learn.
